# 展示样例

三张图片来自本项目已经用于交接演示的 `ds01_remaining` 样例，分别包含多开关面板、
单开关近景和另一单开关角度。这些图片用于功能展示，不构成独立测试集。

`predictions.json` 是官方 `ultralytics==8.3.9` 加载已有标准 YOLO11n-OBB 项目基线
权重后生成的预测，保存图片哈希、模型哈希、四角点、类别和置信度。模型权重单独准备。
回放根据图片 SHA-256 校验身份，方向算法在运行时重新计算。

这些图片不作为可任意再分发的数据集发布；其原始数据许可尚未在本仓库整理。
计划在其他项目中使用时请先确认来源与授权。第三方和公开范围见
[THIRD_PARTY_NOTICE.md](../THIRD_PARTY_NOTICE.md)。
